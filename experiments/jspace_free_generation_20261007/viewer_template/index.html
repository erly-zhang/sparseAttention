Reading guide · Methods, limitations, and sources

Each method independently samples its next token using temperature 0.6, top-p 0.95, batch1 and a private seed42/input-identity random generator. The five methods share the original prompt, not the subsequent token history. Same-step comparisons after divergence are descriptive comparisons of different histories. They do not isolate attention damage.


All 15 traces reached 4,096 generated tokens. Question0 and Question2 remain in the think span; Question1 closes the think span but its final explanation is truncated before a complete boxed answer. Intermediate correct values are not scored as completed final responses. This is not a formal accuracy or efficiency benchmark.


Top8 displays ASCII tokens containing a letter or number. The filter affects display only; ranks, probabilities, Recall@25 and JS use the full vocabulary. Original generated text is preserved without translation. Rank heatmaps track one fixed pinned token, and every cell prints its exact rank or finite-precision tie interval.


Readout: pℓ(v|h) = softmax(WU RMSNorm(Jℓ h))v. Block35 uses J=I. Readout probabilities are before generation temperature and top-p processing. The same frozen Qwen3-4B lens is used for all methods; it was fitted on 479 WikiText sequences of up to128 tokens. It is an average Dense Jacobian, not the exact Jacobian of each sparse path or current reasoning position.


Dense prefill; total K=2048 includes all prompt tokens and recent64. Full KV methods keep the entire history and select before every decode attention. Compact methods attend to surviving KV, then select and physically compact every64 steps when the cache exceeds K. Positions are shared across KV heads within a layer. W1 scores with a current-query representative Q head; Random uses independent Uniform scores and TopK.


Checkpoints occur every128 steps and near sparse boundaries; columns do not represent every token and their spacing is unequal. Each method has its own reasoning-phase labels and context snippets. Step0 captures the last prompt token; step t captures state after consuming t continuation tokens. The final checkpoint is an extra unsampled forward of the last emitted token. Original RoPE positions are retained; abs=prompt_tokens+step−1.


Same prefix as Dense only filters to positions before this method’s first differing consumed token. It can include active sparsity. After divergence, Dense overlays and same-step metrics compare different text histories. Rank lines connect measured checkpoints only. No workspace band, capacity loss, or causal explanation of accuracy is established by these three questions.


Exported from saved residuals without new text generation. Input hashes, pre-sparse residual equality and actual pair counts passed. Every Top8 ID and rank bound is checked against the original A100 readout files; exact full-vocabulary rank streams are independently decoded. Layout follows the earlier local Figure5-style viewer; the earlier fixed-Dense-prefix viewer remains unchanged.
