# English offline J-lens viewer template

These frontend files are copied without changing behavior from the validated
English report. They contain the viewer code and layout, not experiment data.
Copy them into the corresponding exported report directory alongside its
manifest, case JS files and rank chunks. Opening this template alone does not
provide a populated report. The free-generation viewer also expects its local
results and explanatory artifacts. The capture/export scripts remain in the
parent directory; datasets, checkpoints and generated packages stay local.

The original meaningful-token display filter came from jacobian-lens. Its
license and attribution notices are retained beside the template.
