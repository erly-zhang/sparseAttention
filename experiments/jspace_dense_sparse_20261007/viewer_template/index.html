Reading guide · Methods, limitations, and sources
  
Display policy: Top 8 is recomputed from the complete vocabulary after restricting token text to ASCII characters with at least one letter or digit. This is a character filter, not automatic English-language classification. Raw token strings are retained; no token translations are substituted. The English-character Top 8 can differ from the original multilingual wordlike Top 8. Selection algorithms, captured residuals, input prefixes, full-vocabulary ranks, and Recall@25/JS metrics are unchanged.

  
Readout formula: pℓ(v | h) = softmax(WU RMSNorm(Jℓ h))v. Block 35 uses J = I and gives the model’s next-token distribution. No workspace layer band is assumed for Qwen.

  
This viewer uses three completed, paired HMMT samples, each with up to 4,096 Dense continuation tokens. All sparse methods replay the same Dense prefixes, so comparisons use matched positions. These readouts do not measure sparse free-generation accuracy. Prompt prefill uses dense attention.

  
Full KV: select positions from the entire history at every step, without permanently deleting KV. Compact KV: select from the surviving cache every 64 steps and permanently delete other positions; cache length may exceed K between compactions. Both use a total budget K=2048 and protect all prompt tokens plus recent64. W1 scores with representative heads at the current query; Random selects randomly.

  
Actual checkpoints were captured every 128 steps and near sparsity boundaries. Column intervals are unequal; uncaptured tokens have no cells. Trajectory x-axes use actual steps, while each heatmap column represents one checkpoint. Step 0 is the last prompt token at prefill. Absolute positions are zero-based: abs = prompt_tokens + step − 1.

  
Pinned-token ranks are computed independently over the full vocabulary: rmin=1+∑v1[zv>zt], rmax=∑v1[zv≥zt]. Finite-precision ties are shown as [rmin, rmax]. Cells display the exact rank interval; curves and colors use its geometric midpoint. Every Top 8 token displayed across this sample’s methods, positions, and layers can be pinned.

  
The public fixed lens was estimated on short WikiText sequences, which differ from long HMMT reasoning. The earlier J-space reconstruction probe did not outperform its random-dictionary negative control. This viewer describes J-lens readout differences; it does not establish workspace capacity loss or a causal mechanism for reasoning performance. The two Dense kernel controls have bitwise-identical residuals at these K2048 checkpoints.

  
Layout inspired by Figure 5 of the Transformer Circuits 2026 workspace paper. Data come from the local Qwen3-4B HMMT pilot. External links are optional for offline viewing. The original viewer used the meaningful-token filter from jacobian-lens (Apache-2.0, Anthropic PBC). This version additionally restricts display to ASCII tokens containing letters or numbers.
