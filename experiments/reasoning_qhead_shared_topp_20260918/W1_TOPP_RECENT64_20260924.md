# W1 Top-p0.95 + recent64

Implemented at the user's request on2026-09-24. The user explicitly confirmed union semantics: first apply W1 Top-p0.95 across ALL non-prompt positions, then union with the latest64 non-prompt positions. The fixed40% random budget is removed.

For layer l and decode step t, let P be prompt positions and G_t all non-prompt positions currently in full KV. Draw the representative query head h using the existing layer-private RNG (rep_seed0, stable sample identity and layer). Use only the current post-RoPE q_(t,h), and its GQA-mapped KV head g(h):

```
a_j = softmax_{j in P union G_t}(q_(t,h) dot k_(j,g(h)) / sqrt(d))
p_j = a_j / sum_{i in G_t} a_i, j in G_t
S_t = smallest descending-probability prefix with sum p_j >=0.95
T_t = last min(64, |G_t|) non-prompt positions
M_t = P union S_t union T_t
```

The old torch probability sort and boundary handling are reused verbatim. There is no new random token choice or random-score TopK. The representative head remains randomly chosen per layer and step, with a private generator. Each Q head attends using its own query on the shared mask. Indices are chronological and duplicate-free. Current K/V are appended before selection; persistent full KV is never pruned. Dense prefill remains unchanged. For<=64 non-prompt tokens, the final mask retains all legal keys.

Implementation: `ra_harness/kvcompress/engine/w1_recent_shared_mask_cache.py`, method `qhead_shared_mask_w1_recent_gpu`. The selector calls the unmodified historical `SharedMaskLayer.select_indices()` and adds recency. It reuses random-recent full-cache growth and fused K/V gather; unlike the fixed-ratio selector, batch rows can select different counts. Gather padding follows the valid prefix and is excluded by per-row FlashAttention cache lengths. Temporary buffers grow geometrically and are reused. Attention pairs count valid selected positions, not padding. Metrics also separately sum Top-p-core pairs and extra pairs added by recent protection.
